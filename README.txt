ADDING A PROJECT
----------------
1. Put a screenshot of your project in images/projects/
2. Open projects.js
3. Copy the example project object.
4. Change title, category, description, image, technologies, liveUrl and githubUrl.
5. Set featured: true if you want it on the Home page.
6. Save and refresh.

The Home page automatically shows the first 3 featured projects.
View All Projects opens projects.html and shows every project.
